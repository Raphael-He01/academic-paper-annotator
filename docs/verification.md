# 验证范围

## 自动检查能证明什么

发布检查器验证准备好的源数据与静态 HTML 的对应关系：正文、译文状态、批注文本、高亮、表格的归属与行边界、图注与嵌入图像、声明来源、书目非空、范围和摘要一致性。

图像检查只识别受支持格式的基本签名和结构，不是完整图片解码器。表格检查不从截图推断原始行列；来源 rows 必须正确提取。数字字面值、来源状态或人工审阅标记需要真实证据，不能通过改标记代替复核。

## 状态

- `ready`：静态无阻断且记录的内容与浏览器审阅通过，文件摘要相符。
- `ready_with_verification_limits`：静态和内容记录通过，但存在已说明的实际验收限制。
- `checkpoint`：存在内容、来源、结构或审阅阻断，不能称为最终版。
- `not_auditable`：输入缺失或格式错误，无法进行可靠检查；CLI 退出码为 2。

静态检查不能证明翻译语义、论文事实、像素级可见性、复杂图像完整性或浏览器呈现。Node 测试使用模拟 DOM，不能作为真实浏览器测试的替代。
