# 页面、交互、技术与透明度规范（§10–§13）

> 本文件承载 §10–§13：模板规格、图表公式、交互与离线可靠性、技术与透明度。模板建成后，日常执行只需套用模板；改版或校验时回读本文件。生成成品前必读 §13.2。

## 10. 页面与视觉规范

采用 Academic Editorial Design × Swiss Typography × Restrained Bauhaus Geometry：严肃、克制、秩序清楚，少量几何元素，避免过多色块、卡片和装饰。

固定颜色：深海军蓝 `#14253D`；纸张背景 `#FAF8F3`；中文译文背景 `#F0ECE2`；正文 `#2B2F36`；辅助文字 `#5F6570`（在 `#FAF8F3` 上对比度 5.5:1，在 `#F0ECE2` 上 5.0:1，满足 WCAG AA。原先常用的 `#737983` 只有 4.1:1 和 3.7:1，均不达标）。五色高亮采用 §7.1 的固定映射和柔和背景；`#2B2F36` 在五种高亮底色上的对比度均在 5.8:1 以上。

字体：英文原文优先 Lora；英文界面优先 IBM Plex Sans；中文正文优先学术阅读友好的衬线字体；中文界面与批注优先清晰的无衬线字体。可合法嵌入且条件允许时嵌入字体（子集化以控制体积）；否则使用系统字体回退，不为满足字体名称强制联网。

参考字号：英文 16–18px、中文 15–17px、批注 14–16px；行高约 1.7–1.95。控制行长，避免超宽正文。

页面依次包含：

- 深海军蓝顶部栏：简短标题、来源信息、五色图例及阅读工具。
- 导读卡（§9.1）。
- 元信息区：完整标题、作者、年份、发表平台、DOI、论文类型、领域、研究问题、来源版本、许可、处理状态。推断字段标为分析判断，缺失字段不猜测。
- Sticky 章节导航：真实章节对应、当前章节、阅读进度。
- 双语逐段阅读区及章节总结。
- 全文论证地图与批判性评价。
- 术语索引及 Source & Analysis Notes。

桌面采用逐段 CSS Grid，左右约 64:36。一个阅读单元包含左侧英文及紧接其后的中文译文、右侧对应批注。禁止把全文和全部批注做成彼此独立的两根长列——那样读者需要在两列间来回找对应关系，逐段对照的意义就没了。

中文译文使用浅米色背景、2–3px 左侧细线及适当内边距，与英文区使用细分隔线区分。高亮保留在英文原文中。

移动端每个单元依次排列英文、译文、批注；导航可横向滚动。长表格和公式仅在自身容器内滚动，避免页面级横向溢出。

## 11. 图、表、公式与论证图

### 11.1 图像

- 图像以**页面区域栅格化裁剪**为准：按 `bbox` 从 PDF 页面渲染后裁剪（如 300 dpi），而不是抽取内嵌图片对象。后者会丢矢量图、拆散复合面板、丢失图内文字。测试集实测：论文 B 的全部图是矢量图，页面内嵌栅格图数为 0，抽取内嵌图对象会得到空结果；多面板图只看图注含"(a)"只是下限，必须渲染页面目测核对。
- 嵌入图像总体积设上限（建议 15 MB），超限时按分辨率递减重采样，并在 Source & Analysis Notes 记录压缩参数。
- 无法可靠提取时，保留可读取的完整图注、图号与来源页，使用明确的缺失提示，不伪造图像，不用生成图像替代实验图。

### 11.2 表格与公式

- 表格优先用语义化 HTML 保留结构、标题、单位、注释和显著性标记；翻译表头与文字说明时保留英文对应，数据和符号保持原样。无法可靠重建时保留原始图像及已核实内容，标明限制，不补造单元格。
- 公式以**页面裁剪图为准**，你转写的 MathML 作为可选的可访问性层，并标注"转写待核"。从图像转写公式和重打原文是同一类保真风险：看上去对，细节（上下标、括号范围、下标变量）容易错。
- 公式保留所有变量、上下标、符号、编号和成立条件。必须有可用的离线数学呈现：裁剪图 + alt 文本即可满足；若采用嵌入式渲染器，资源包含在文件中，并准备可读降级方案。
- 算法保留步骤顺序、缩进和符号。说明图表、公式及算法在论证中的作用，不只复述标题。

### 11.3 论证图数据结构

```json
{
  "nodes": [
    {"id": "n1", "kind": "question|gap|assumption|method|evidence|interpretation|limitation|conclusion",
     "label": "一行中文", "units": ["P007", "P014"], "layer": 0}
  ],
  "edges": [
    {"from": "n1", "to": "n4", "relation": "supports|depends_on|qualifies|rebuts", "note": "可选一行说明"}
  ]
}
```

`layer` 由依赖关系拓扑排序得出，同层横向排列，模板按固定分层布局渲染（SVG，节点可点击跳段）。不要让渲染自由发挥——手写坐标在节点稍多时就会重叠错位。节点超过约 18 个时按章节分组出多张子图，并保留一张概览图。文字版等价列表始终生成。

## 12. 核心交互与离线可靠性

使用原生 JavaScript，核心内容直接存在于静态 HTML 中。JavaScript 失效时，原文、译文、批注和来源仍可阅读。

必须实现：

1. **阅读模式**：Bilingual 显示原文与译文，批注独立开关；English Only 显示英文原文与必要来源信息；Annotation Focus 突出批注并保留定位及查看原文的入口。只改变呈现，不删除内容；切换模式后能够完整恢复。
2. **深读过滤**：只看 deep 段落 / 显示全部（§6.1）。
3. **五类高亮独立开关**；关闭仅移除视觉效果，不隐藏文字。
4. 全部展开、全部折叠及单段批注展开；键盘可操作。
5. 章节与段落定位、当前阅读单元提示及跨段返回链接。
6. 阅读进度及当前章节状态；避免把浏览进度称为知识掌握程度。
7. 关键词搜索、结果数量、上一个/下一个结果及清除；匹配样式区别于学术高亮，跳转可展开被折叠区域。
8. 打印入口和可靠打印样式。

状态保存与个人笔记属于可选增强：使用带来源标识与数据版本的本地存储，失败时降级；若提供个人笔记，支持 JSON 导出与导入，并验证文件结构。不得要求登录或连接第三方服务。

搜索、折叠、阅读模式和状态恢复不得改写原文数据、破坏高亮或造成内容丢失。文件打开方式、浏览器限制或存储不可用不能阻止阅读。

## 13. 技术、无障碍、打印与透明度

交付 UTF-8 HTML5 单文件，推荐命名 `Paper_Title_Academic_Annotated.html`。CSS 与 JavaScript 内联；必要图像、字体和数学资源尽量嵌入。不依赖 React、Vue、后端、在线 API 或外部 CDN 才能阅读。

合理使用 `header`、`nav`、`main`、`section`、`article`、`aside`、`footer`、`mark`、`figure` 和 `table`。明确语言属性（英文区 `lang="en"`、译文区 `lang="zh-CN"`）、标题层级、表格表头、图像说明和按钮状态；提供聚焦样式、跳过导航入口、合理触摸面积及减少动画支持。Sticky 元素不得遮挡跳转目标或正文。

对插入的论文与用户内容正确转义，避免将其当作脚本执行；不添加跟踪器，不自动上传论文、阅读状态或笔记。

打印时：隐藏无关控件，取消 sticky，打印完整双语内容及全部批注，不受当前折叠、搜索或阅读模式影响；保留标题、来源、编号和必要高亮。可临时展开后恢复阅读状态。长单元允许合理跨页，避免强制不分页形成大片留白；重复表头，防止公式和表格被裁切。

### 13.1 外部资料

外部检索仅用于必要背景、术语、方法、版本及事实核实。优先原始论文、官方文档、权威方法资料，明确出处及用途。外部资料不替代未读取的论文内容，也不与作者证据混写。

### 13.2 Source & Analysis Notes

必须记录：

- 原始文件、来源链接或 DOI、版本、许可。
- 文本基准格式及其选取理由（§3.1）。
- 实际处理范围，以及各类内容的保留、翻译、批注、核验四项状态。
- 编号与来源定位规则。
- 提取方式、修复记录和核验范围，以及未解决事项。
- 中文译文为 AI 辅助译文；批注与论证图包含分析性重构。
- 哪些文献、数据、代码、结果或复现结论未经独立核验。
- 使用的外部资料及其对应解释。
- 机检、内容复核、浏览器验证各自的执行范围与结果，以及未执行项目。

不披露无关内部操作过程，不声称未做过的验证已经完成。
