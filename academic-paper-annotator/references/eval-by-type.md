# 按研究类型调整评价（§14）

## 14. 按研究类型调整评价

> 每篇论文通常只用到其中一两类，只读与论文相关的类型。

只应用与论文相关的标准，不把不适用项目判为缺陷。

**实证研究**：研究问题、假设、数据来源、样本、变量、对照、设计、指标、统计分析、效应大小、不确定性与外推条件。区分预设分析与探索性分析，注意多重比较、缺失数据、选择性报告及混杂，但每项判断均需证据。

**AI / ML**：训练、验证、测试划分及独立性，潜在数据泄漏，数据集偏差，基线比较公平性，调参与计算资源，消融，重复运行或适当的不确定性估计，外部与分布外验证，计算成本及复现材料。区分代码可获取、结果可复现和已实际复现。基准成绩只能支持相应测试条件下的结论。

**医学与临床 AI**：队列、纳排标准、患者层面划分、参考标准、终点、患病率、敏感度、特异度、AUROC / AUPRC、校准、临床阈值、亚组表现、外部验证、混杂及临床效用。区分回顾性与前瞻性、诊断与预后、预测表现与患者获益。未报告的指标不得自行计算或补造；有充分原始数据且进行计算时，必须标为分析者计算并说明方法。小样本须写出分母与事件数（例如测试集 n 与阳性数）和置信区间宽度，译文与批注不得把点估计写成确定结论；只有部分患者具备金标准时（验证偏倚），说明被选入的子集与被排除或重复的记录。

**理论研究**：定义、假设、引理、命题、定理、证明依赖及适用条件。区分已证明结论、直觉解释、猜想、例子与数值验证；不套用实验研究模板。

**综述与证据综合**：先区分叙述性、范围性和系统性综述，再评价检索与筛选、分类框架、质量评价、异质性、矛盾证据及综合方式。不以系统综述的全部要求直接否定叙述性综述。

**数学 / 方法类综述**：不套用实验论文模板，也不要求检索与筛选流程。评价覆盖范围与分类框架是否清楚、定义与定理的陈述是否准确、符号是否前后一致、不同方法之间的比较是否公平、对作者自己没有证明的结论是否如实标注来源。篇幅很大时，按 §4.4 的降级顺序处理，参考文献列表保留但默认不逐条翻译。

**其他类型**（质性研究、系统与工程论文、立场或观点文章、数据集与基准论文、工具论文等）：从论文自身的成立条件出发，先问"这类工作要让人相信结论，需要满足什么"，再据此评价。不套用上述任一模板，并在 Source & Analysis Notes 说明所用标准的来源。

对关键实验说明：验证什么、用什么数据和方法、与谁比较、观察到什么、支持什么、仍不能支持什么。
